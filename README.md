# markdown-workspace

A minimal markdown‑only workspace app.

- Stores all content in the `data/` folder.
- A tiny Express server serves the static front‑end.
- Uses Marked.js to render Markdown.
- Deployable to Netlify, Vercel, or any static host.

## Getting started

```bash
# Clone the repo
git clone https://github.com/aicenter947-lang/markdown-workspace.git
cd markdown-workspace

# Install deps
npm install

# Start dev server
npm run dev
```

Open `http://localhost:3000` and use the buttons to switch views.
